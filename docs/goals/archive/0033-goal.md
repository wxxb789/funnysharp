/goal
Enable a FunnySharp consumer to reduce a sequence through a fallible accumulator and stop consuming the source as soon as the selected failure semantics require it, without materializing a result sequence or manually managing an enumerator. Completion means parsing and checked accumulation over an ordinary enumerable can return the final accumulator or the first domain failure while making no subsequent source MoveNext or step calls, and a meaningful asynchronous-source or asynchronous-step path preserves the same observable contract. Empty input returns the explicitly supplied seed; single-pass and deferred sources, source exceptions, step exceptions, cancellation, disposal and mutable accumulator behavior must be accurately described. Failure must not imply rollback of mutation or external work already performed, and arbitrary exceptions must not silently become expected domain errors. Completion evidence includes a source that exposes consumption and disposal, a complete equivalent foreach or await foreach reference and a comparison to Aggregate over Result that demonstrates the actual upstream short-circuit difference. The maintainer evaluates consumer clarity and code reduction with allocation, copying and buffering costs disclosed for realistic accumulators. Preserve standard .NET sequence types, existing typed Result outcomes and explicit cancellation; avoid a new stream hierarchy, synchronous blocking, a generic early-exit protocol larger than the use case, or automatic parallel reduction without valid algebraic assumptions. This is a distinct outcome from Goal 0034's combination of reusable summaries.
