/goal
Provide FunnySharp with a deliberately thin effect boundary that makes dependencies, failures, cancellation, and resource lifetime visible while continuing to use standard .NET execution primitives. Completion means effectful computations can be composed without eagerly running them, can depend on an explicit environment where useful, and can safely acquire/use/release IDisposable and IAsyncDisposable resources across success, failure, exception, and cancellation. Interoperation with Func delegates, Result, Task, ValueTask, CancellationToken, TimeProvider, and ordinary dependency injection must be straightforward. The feature must not introduce its own scheduler, fiber runtime, dependency-injection container, higher-kinded-type emulation, monad-transformer stack, or large IO universe. Evidence must include xUnit v3 tests proving exactly-once cleanup and correct error/cancellation propagation, compiling synchronous and asynchronous examples, and measurements of wrapper and composition overhead relative to direct .NET code.
