/goal
Make partial updates first-class, typed and inspectable in FunnySharp so an application can decode an allowed change, validate it against current data, preview its meaning and apply it without confusing omission with an explicit null or replacement value. Completion means an executable profile or scheduling update handles unchanged fields, explicit clearing, allowed replacements, rejected fields and a cross-field constraint that depends on both submitted and existing values, returning a useful result rather than scattering those distinctions through controller and domain code. The change representation must compose coherently with decoding, Result or Validation and optional immutable updates; its default value, equality and conflict behavior must be deliberate, and it must not weaken Option.Some's existing null contract merely to encode a patch. Validation must describe the candidate resulting state rather than incorrectly checking only supplied fields. Applying a change must disclose whether it creates a value or mutates a caller-owned object, what happens if a callback fails, and which original state or version its validation applies to. Combining changes must expose conflicting writes rather than silently imply a universal merge policy; inverse changes or rollback may be promised only when the necessary prior information and execution guarantees actually exist. Completion evidence is an ordinary C# comparison including JSON or request binding, rule reuse and error mapping, boundary examples for those distinctions and measured copying and allocation for realistic updates; the maintainer judges clarity and consumer-code reduction. Retain .NET primitives and ORM independence, with optional System.Text.Json and ASP.NET Core integration using explicit wire semantics. Database uniqueness, concurrent writes and external side effects remain subject to their real storage or execution guarantees. Goals 0026 and 0027 may supply reusable decoding and rule descriptions, but this outcome must not require a general transaction engine.
